🛡️ Simple Honeypot

A lightweight Python-based honeypot that simulates multiple network services and records attacker activity.

Features
SSH Honeypot
HTTP Honeypot
FTP Honeypot
JSON Logging
Log File Generation
Payload Capture
Multi-threaded Server
Connection Logging
Technologies
Python
socketserver
threading
logging
json
sockets
Ports
Service	Port
SSH	2222
HTTP	8080
FTP	2121
Installation
git clone https://github.com/yourusername/Simple-Honeypot.git
cd Simple-Honeypot
python simple_honeypot.py
